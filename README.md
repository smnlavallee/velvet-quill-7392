# loremtype

Minimalist Monkeytype-style typing test built with Flutter Web and hosted directly on GitHub Pages.

**Live preview:** https://smnlavallee.github.io/velvet-quill-7392/

## Features

- Single-page Monkeytype-inspired experience (no login, no tracking, no persistence)
- Language dropdown switcher for **English**, **French**, and **Lorem Ipsum**, each backed by a 100-word pool
- Fresh randomized sequence on every reset/restart across `10` / `25` / `50` / `100` word modes
- Optional `@ punctuation` and `# numbers` toggles
- Live WPM tracking while typing, plus WPM, accuracy %, elapsed time, and character stats on completion
- Bottom **Reset** button upon completion to immediately start a new randomized session
