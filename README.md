# loremtype

Minimalist Monkeytype-style Lorem Ipsum typing test built with Flutter Web and hosted directly on GitHub Pages.

**Live preview:** https://smnlavallee.github.io/velvet-quill-7392/

## Features

- Single-page Monkeytype-inspired experience (no login, no tracking, no persistence)
- Deterministic Lorem Ipsum passages selectable up to 100 words (`10` / `25` / `50` / `100`)
- Optional `@ punctuation` and `# numbers` toggles
- Live WPM tracking while typing, plus WPM, accuracy %, elapsed time, and character stats on completion
- Bottom **Reset** button upon completion to restart immediately with the same words
